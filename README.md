# 🏠 Sri Lanka House Price Prediction

This project predicts house prices in Sri Lanka using Machine Learning.

## 🔍 Features
- Feature Engineering
- One-Hot Encoding
- Linear Regression
- Random Forest
- Model Evaluation (RMSE, R2)

## 🛠 Technologies
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## 📊 Goal
To build a regression model that predicts house prices accurately.
